## Applied changes

- Remove readable session passphrase caching and signer PEM/key caching; leave credential textareas blank. Mount idle enforcement above routes and enforce an elapsed deadline on resume.
- Fence quote POSTs with run-generation/credential ownership at the final fetch boundary and each retry; block restart during an active tick. Compensate accepted legs after a later placement failure or a stop observed on response. Unknown HTTP outcomes still require durable reconciliation.
- Replace redundant mirrored four-leg quoting with one YES bid/ask pair. Add prospective order-count, conservative aggregate exposure and collateral checks. Add maker-only and short exchange expiry controls; demo confirmation of legacy endpoint behavior is still required.
- Fail closed on critical spot/account/market refresh exceptions and failed cancels; refuse to cancel unrecognized orders during routine quoting. Improve kill results and block flatten while unresolved orders remain. Flatten uses reduce-only bounded-price limit intent, whose completion is reconciled; slippage policy, stop serialization and account scope still require work.
- Normalize legacy/fixed-point order and position fields; use remaining order quantity and correct side price. Drain cursor pages for orders, positions and fills; reject cursor loops and incomplete/malformed list responses. Market and orderbook normalization remains outstanding.
- Calculate equity from cash plus portfolio value, establish the first confirmed baseline, and run loss checks before quoting. Persisted daily/cycle accounting and meaningful unrealized P&L remain outstanding.
- Preserve risk defaults when loading older local settings. Avoid full ledger closure on partial fills as a conservative measure; cumulative remaining fill accounting is still outstanding.
- Require explicit market selection after rollover. Quantize bids down/asks up to preserve the ratio. Require a positive known start balance, validate the exact saved PEM and prevent credential changes while running.
- Associate risk/strategy controls with labels, wrap the dashboard header, clear mismatch history during local deletion and correct overconfident stop status text.
- Remove unsafe-eval, allow the Coinbase candle origin in all three policy sources, add upstream/browser request deadlines and forward Retry-After. Actual host header enforcement, public proxy restrictions and resource budgets remain outstanding.
- Correct no-fill backtest hit rate and clamp-equality artifacts, filter unclosed candles, align drawdown’s initial peak and label the result a synthetic pricing demonstration. This does not provide a realistic historical execution backtest.
- Regenerate package-lock.json without running install scripts, add a standalone isolated regression command, add the email rate-limit status migration, scope service-worker cache cleanup, bound navigation fallback, update disclosure URLs and configure Caddy precompressed assets.
